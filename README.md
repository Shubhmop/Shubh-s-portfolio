# Shubh's Portfolio

Welcome to the official repository for my personal portfolio website. This site showcases my work, projects, and skills in a clean, interactive single-page layout.

---

## 🚀 Features

* **Responsive Design:** Optimized for seamless viewing on desktops, tablets, and mobile devices.
* **Monetization Ready:** Configured with Google AdSense integration via custom verification snippets (`ads.txt`).


* **Fast Performance:** Built using standard web technologies for lightweight and fast loading times.



---

## 🛠️ Project Structure

```text
Shubh-s-portfolio/
├── index.html   # Main website structure and content
├── README.md    # Repository documentation
└── ads.txt      # AdSense authorization configuration

```

---

## 💻 Tech Stack

* **HTML5** – Site structure and layout


* **CSS3** – Styling and responsive design
* **JavaScript** – Interactive elements and functionality

## 🔧 Local Setup

To run this repository locally on your machine:

1. **Clone the repository:**
```bash
git clone https://github.com/Shubhmop/Shubh-s-portfolio.git

```


2. **Navigate to the directory:**
```bash
cd Shubh-s-portfolio

```


3. **Open the site:**
Simply double-click `index.html` or open it directly in any web browser.
